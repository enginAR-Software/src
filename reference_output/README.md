# Reference outputs

- `demo/`: output of `python3 -m fieldshift_data demo` for version 1.0.0, run offline on the packaged data on 15 November 2026. Open `demo/FieldShift_App.html` or `demo/DASHBOARD.html` in a browser; `demo/DEMO.md` is the printed summary.
